# Scope and limits of Timeline 1966 verification

The [Timeline manifest](../../TGC_Timeline_1966/docs/manifest_1966_timeline.md)
defines the core/Timeline composition and the inventory of full-file overrides.
Use the [validator and drift reference](1966_extension_validator.md) for the
structural guarantees and their declared scope.

The [balance auditor reference](1966_balance_audit.md) explains which findings
come from raw script, which use the applied subset verified for Project Alice
1.3.0, and where Victoria II semantics still need evidence. Numerical bands
remain provisional. A successful static run establishes the checks performed
for the selected composition. Gameplay balance, runtime stability and
functional compatibility on each engine require separate evidence.

See the [re-baseline backlog](../../docs/rebaseline_backlog.md) for open
runtime, compatibility and balance questions.
